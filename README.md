# Test Strategies With Hexagonal Architecture

## Pre-requisites

- Docker
- Docker Compose v2
- Task

## How to use the demo

Set up the application and start the database with `task up`.

You are now ready to run the tests.

The full list of actions can be accessed by running the following command in your usual terminal:

```bash
$ task
```
